# Mandatory human checkpoint matrix

No checkpoint may be crossed automatically.

| Checkpoint | Evidence and approval required | Unlocks | Current state |
|---|---|---|---|
| 1 — Source Control Scope | every required/excluded file, individual original 60-file accounting, commit split, generated bundle/source pairing, owner approval | controlled staging/committing in a separate authorized task | pending |
| 2 — Staging Provisioning | isolated Spreadsheet/project, backup, authorized operator, project owner, rollback owner | configuration review and read-only identity check | blocked |
| 3 — Configuration | Script Property evidence, both pins = active Staging ID, frontend Staging URL fingerprint, `LEGACY`, detector/conflict/live/override flags false, zero triggers | Migration Preview | blocked |
| 4 — Migration Preview | Identity → Phase 1 → 2 → 3 → 4 → 5 evidence; all zero-write; schemas/counts reviewed; order accepted | proposal for separately authorized migration execution | blocked |
| 5 — Staging Runtime Testing | explicit owner approval, approved migration/backup/rollback/monitoring, account/data matrices | separately authorized writes/E2E/concurrency tests in isolated Staging | blocked |

Checkpoint 5 approval is required before any migration execution, Apps Script write test, booking E2E, attendance write, payroll settlement write, or concurrency test. PHASE5, conflict resolution, detector execution, and trigger installation each require later explicit approvals beyond this matrix.
