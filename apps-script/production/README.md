# Production Apps Script package

هذه ملفات مشروع Google Apps Script الفعلي، مقسمة من **نسخة الإنتاج 38** التي تمت قراءتها في 8 أكتوبر 2026.

الكود المنشور كان مختلفًا عن نسخة التطوير المحلية في `backend/`، خصوصًا إدارة الموظفين ومعاملاتهم. لذلك تم تقسيم كود الإنتاج نفسه، دون استبداله بكود التطوير المحلي.

تم نشر هذه الحزمة كنسخة **39** على نفس مشروع ورابط الإنتاج. قراءة نسخة النشر أكدت مطابقة الملفات، واختبار رفض الطلب بدون جلسة نجح. التفاصيل في `docs/backend-refactor-production-deployment.md`.

- 89 ملف `.gs`، بأسماء توضّح المسؤولية.
- الأرقام في أسماء الملفات تحافظ على ترتيب التهيئة الأصلي.
- `appsscript.json` يحتفظ بإعدادات المشروع الأصلية.
- `source-map.json` يسجّل ترتيب الملفات وربطها بالملفين الأصليين وبصماتهما.
- تم إثبات تطابق إعادة التجميع حرفيًا، ومقارنة 811 دالة وواجهة محرك قبل الفصل وبعده.

الفحص المحلي:

```sh
node scripts/build-production-apps-script.js
node --test tests/production-backend-modularization.test.js
```

هذه حزمة الإنتاج المستقلة. لا ترفع معها ملفي التشغيل القديمين أو ملفات `backend/`، لأن ذلك يكرر التعريفات. `backend/` يحتفظ بمصدر نسخة التطوير المحلية وطريقة تجميعها السابقة؛ لم يتم محو تعديلات التطوير عند تجهيز الإنتاج.

للتعديلات اللاحقة على الإنتاج، استخدم هذه الملفات كأساس للمراجعة. بصمات `source-map.json` تخص عملية التقسيم الحالية وتمنع تعديل الحزمة بالخطأ؛ تغيير السلوك عمدًا يحتاج تحديث حزمة المراجعة وبصماتها واختباراته، مع الاحتفاظ بنسخة ما قبل التعديل.
